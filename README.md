## Overview

FitJacket is a full-stack fitness web application designed to transform your fitness journey. It enables users to create custom workout routines, explore exercises with visual demos, and seamlessly plan/log workouts with Google Calendar integration. Powered by an AI fitness chatbot (Gemini 1.5-Flash) and extensive exercise APIs, FitJacket provides an intelligent, personalized, and supportive experience for everyone from beginners to seasoned gym-goers.

## Getting Started

### Prerequisites

This project requires the following dependencies:

- **Programming Language:** Python
- **Package Manager:** Pip

### Installation

Build FitJacket from the source and install dependencies:

1.  **Clone the repository:**
    ```sh
    git clone [https://github.com/shora051/FitJacket](https://github.com/shora051/FitJacket)
    ```
2.  **Navigate to the project directory:**
    ```sh
    cd FitJacket
    ```
3.  **Install the required packages:**
    ```sh
    pip install -r requirements.txt
    ```

## Functions

Learn Exercises: Talk to a AI-powered fitness chatbot to find exercises and learn how to properly perform those exercises.

Create Plan: Save your workout routines in a centralized system - put in specific exercises and reps.

Workout Calendar: Plan your future workouts and rest days. Also, make sure to log your workouts daily.

Workout Log: Track your progress over time by viewing and editing your workout logs.
